# ☁️ AWS & Terraform Hands-on Labs: The DevOps Journey

## 🎯 Overview
This repository documents my intensive hands-on journey into Cloud Infrastructure and Infrastructure as Code (IaC). It serves as a practical portfolio demonstrating my progression from basic cloud resources to production-ready, highly available architectures on AWS using Terraform. 

This project is a core part of my preparation for the **AWS Certified Solutions Architect – Associate (SAA-C03)** certification.

## 🧰 Tech Stack & Tools
- **Cloud Provider:** Amazon Web Services (AWS)
- **Infrastructure as Code:** Terraform (HCL)
- **OS & Scripting:** Linux (Ubuntu), Bash Scripting
- **Core AWS Services:** VPC, EC2, ASG, S3, IAM, ALB, CloudWatch, etc.

## 📂 Repository Structure (Learning Path)
This repository is organized into progressive learning phases. Specific micro-labs and projects are continuously added and structured by topic as the journey progresses.

- **Phase 1: AWS Core & IaC Muscle Memory** (Networking, Compute, Storage, and Security fundamentals) - *🔄 In Progress*
- **Phase 2: OS & Containerization** (Linux internals, Bash Scripting, Docker) - *⏳ Upcoming*
- **Phase 3: Certification Preparation** (SAA-C03 & Terraform Associate) - *⏳ Upcoming*
- **Phase 4: Real-world CI/CD Projects** (GitHub Actions, Multi-tier Architectures, Observability) - *⏳ Upcoming*

## 🧠 Core Engineering Principles Applied
- **High Availability (HA):** Designing multi-AZ architectures that survive single points of failure (Data Center outages).
- **Don't Repeat Yourself (DRY):** Modularizing IaC configurations and reusing network logic.
- **FinOps Awareness:** Strictly enforcing `terraform destroy` after every lab session to prevent resource leakage and optimize cloud costs.
- **Security First:** Applying strict Security Group ingress/egress rules and isolated VPC designs.
